# Material 界面与学习体验

- 保留茶词浮动导航，统一页面色彩层级、分组列表、搜索框和状态反馈；小屏采用紧凑标题与操作区，保留系统字体缩放。
- 学习首页按词书进度、花瓣形学习入口及复习／收藏快捷入口组织；收藏打开生词本，查询词条后可返回收藏页。
- 词书选择支持实际分类、名称搜索和多选，顶部显示不重复词数，单本已学数来自答题记录。`countBookWords` 使用只读去重查询，避免为了数字解码整批词条；不改变词书或学习数据结构。
- 设置采用固定顶栏和分层面板，背景不缩放；顶栏下拉超过 80dp 关闭当前层，小幅拖动回弹，正文滑动只滚动列表。子页关闭或返回仅回到设置主页。
- 主页定制预览直接绘制真实 HomeView 与导航，包含当前文字、壁纸和主题；搜索框在首页与查询结果之间使用共享元素过渡，结果页不重复显示标题栏。
- 知识画像区分自评与测试证据，零数据时简化展示。固定顶栏不挂接大标题折叠手势，统计和查询列表可以正常上滑。

## 设计参考

Material 页面层级与分组列表参考 [KernelSU Style UI Kit](https://github.com/chenaizhang/KernelSU-Style-UI-Kit)（GPL-3.0）；组件基于茶词现有 Compose API 实现，没有引入 Miuix。关于页包含相应致谢。学习首页和词书选择的布局依据用户提供的参考图实现，未复制第三方应用的代码、课程、封面图片或数据。

## 验证

使用项目现有 Gradle 配置构建 debug APK、设备测试 APK，并运行单元测试与 lint。若默认 K2 UAST 模式中的 Lifecycle 检测器内部崩溃，本机使用 `-Dlint.use.k2.uast=false` 完成分析，不关闭检查项。

真机覆盖浅色／深色／纯黑／动态配色、大字体、小屏、键盘、长释义、设置顶栏与下拉、导航、预测返回、学习续学、收藏查询、词书筛选与多选、统计和结果页的真实触摸滚动。去重查询与原有词书并集结果对照验证。

开发时可通过 `-PverificationAppSuffix=.materialreview` 生成与正式版并存的预览包。调试安装包、截图、测试日志及本轮开始时的 UI 备份保存在本机被忽略的 `validation/material-refresh/`；不随源码推送。原版沉浸背词页的单文件恢复已通过编译验证。
