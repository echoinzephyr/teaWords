# 单词分轮学习

每组默认 5 个词，可调整每轮词数。整组完成一次认读，再开始两轮巩固；不会让同一个生词连续回答三道题。

1. **认读整组单词**：先隐藏释义，选择“认识”或“不认识”后展示中文、发音和可用搭配。“记住了，开始巩固”保存本词认读进度并转向下一个词。自评本身不算答对测试。
2. **第一轮巩固**：整组认读结束后，依次辨认已接触的搭配或根据中文辨认英文。没有可用搭配时使用本地词义反向辨认，不编造例句。
3. **第二轮巩固**：根据中文拼写英文。看提示或答错不获得本步骤的完成点。回看讲解后先练其他词，再返回未通过的词；本轮词太少时仍可能较快遇到同词。

三个点分别表示认读、第一次巩固和第二次巩固的实际进度。全部完成后才增加本轮完成词数。每一步、原认读自评、轮次位置、错误和提示使用情况保存在原有轮次 JSON 内；退后台或退出后可继续。

下拉查词、左滑拼写、词卡收藏和笔记继续可用。辅助查词不自动提交学习答案。离开输入页清除焦点并收起键盘；单词标题按可用宽度和系统字号测量排版。

## 记录与记忆模型

- 认读后紧接的巩固属于辅助学习，一组内三个点不等于三次独立回忆。每个词完成整套流程只写一次学习记录；辅助学习不提高独立回忆通过次数、能力估计或验证置信度，也不因一次看讲解抹去此前的独立回忆记录。
- 普通独立回忆继续使用 FSRS-4.5 默认参数。修正难度均值回归基准、稳定度更新使用旧难度、遗忘公式指数项。公式参考：[FSRS-4.5 模型说明](https://open-spaced-repetition.github.io/ts-fsrs/guide/model/fsrs-4dot5)。这不是已拟合的个人模型。
- 错误或揭示答案的独立回忆安排在至多 10 分钟后重新复习；首次正确回忆至多一天。短学习间隔属于产品策略，独立于 FSRS 记忆状态方程。
- 答得快不再直接判作 Easy。能力估计的先验信息只计一次，置信区间不因重复加入先验而过早缩窄。旧估计读取时纠正不可能的过量信息，保留原能力位置。
- 后续答题读取已保存的 BKT 后验；认读与辅助练习不增加独立证据次数。到期复习不会被“可能已认识”的新词筛选跳过。

## 内容和兼容

搭配优先使用现有本地数据，在线补充只存在于当前界面与进程内有界缓存，不写入轮次文件。词义、义项及既有学习身份不变。对极小个人词库使用少量固定基础词作干扰项，避免出现只有一个答案的假选择题。

轮次新增字段向后兼容；老轮次已完成的词保留完成状态，剩余词按实际步骤继续。Android 7 起可用，未新增大型 SDK，浮动导航不变。
