# teaWords 1.2.3 RC1

这是候选测试版，可在“检查更新”中开启“接收 Beta 更新”获取。

- 单词学习改为整组分轮：先认读本组单词，点“认识／不认识”后看释义和用法，再分别进行辨认与拼写巩固。每个词三个步骤完成后才计入本轮完成数；错词回看后穿插重练。
- 默认每轮 5 词，保留其他每轮词数选项及暂停续学。三个进度点显示实际步骤，不把同一轮的三步当成三次独立记忆证据。
- 增加学习页下拉查词，保留左滑拼写、收藏、笔记和发音。修复离开输入页后键盘残留，改善长单词、大字体及壁纸上的文字可读性。
- 更新双语气泡与茶叶图标。Android 12 起，应用开启动态取色后，桌面图标也会切换到系统 Monet 配色；桌面刷新速度取决于启动器。
- 修复圆角选项按压时四角出现矩形遮罩，放大设置主标题。
- 修正 FSRS-4.5 部分公式、能力估计重复累计先验及后续答题未沿用已保存记忆后验的问题；保留原有词汇、收藏、笔记和历史记录。

仍兼容 Android 7 及以上。服务器文件继续在本地准备，本版未配置阿里云。
